Implemented rig presentations: breathing idle, forward/back walking stride, jump squat,
airborne pose, landing crouch, dash position/trail, attack anticipation/strike/recovery,
guard, hit reaction, victory arm raise, defeated tilt. Cloth has secondary movement.
These are procedural poses, **not** 33 finished frame-by-frame animations. Not all moves
have distinct bespoke choreography. No sprite atlas or individual frame export exists yet.

Source SVG files are editable separately. `npm run assets:export` (run by `predev:web`
and `prebuild`) splits the arena source into the five runtime layers and `manifest.json`;
an asset test verifies the manifest, layer IDs and source correspondence, so layers go
missing only if the exporter contract breaks. Missing arena files at runtime trigger an
in-game error and a loading overlay states progress. Vite inlines small portraits; layer
SVGs are served from `public/`, quality-tiered by request width (960/1280/1600). Asset
tests check files, dimensions and data-driven cancel references. Atlas/animation
metadata validation is pending. These remain original vector/procedural illustrations,
not painted production sprites.
